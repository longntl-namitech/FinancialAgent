## Decided

### Q1 - Branch and PR target
**Answer:** "không cần, thẳng vào main" - no `dev` branch; target `main`.
**Rationale:** the repo has no `dev` and the user does not want one.
**Consequences:** no `dev` branch is created. Work happens on a feature branch (`refactor/restructure-readme`) cut from `main`, and the PR targets `main`. This keeps the global "never commit directly to `main`" rule; if the user meant committing straight onto `main` with no PR, they should say so.
**Date:** 2026-11-18

### Q2 - Target layout
**Answer:** "ok" to option (a): a single package `financial_agent/` holding `api/` (app, routers, auth), `agents/` (the graph and its sub-graphs), `memory/`, `core/` (config, logger, utils, models). Run with `uvicorn financial_agent.app:app`.
**Rationale:** removes generic top-level names (`model`, `memory`, `utils`) and the `graph` package importing itself.
**Consequences:** every import changes; `python app.py` and `uvicorn.run("app:app")` change; the exact sub-folder split is my call, to be written in the spec.
**Date:** 2026-11-18

### Q3 - How far the restructure goes
**Answer:** "a" - moves and import fixes only, plus renaming the folder `file_controler` to `file_controller`.
**Rationale:** every changed line traces to the restructure; behaviour stays the same.
**Consequences:** `upload_dir` duplicate, unused `update_memory` import, possibly unused `convert_to_message` / `get_session_id`, missing tests and LICENSE are listed in the PR description, not changed. Verification is import-and-boot with dummy env vars, since there are no tests. The rename opened Q8.
**Date:** 2026-11-18

### Q8 - Runtime name string `"file_controler"`
**Answer:** "duyệt tất cả grill" - accepted the recommendation: keep the string unchanged at runtime.
**Rationale:** `graph/graph.py:20`, `graph/file_controler/graph.py:24,32` and `graph/supervisor/prompt.py:10` use it as node id, agent name and supervisor routing key; it is also streamed to clients. Changing it is a behaviour change.
**Consequences:** only the folder and Python imports are renamed.
**Date:** 2026-11-18

### Q4 - Packaging
**Answer:** accepted the recommendation: keep `requirements.txt`, no `pyproject.toml`.
**Rationale:** no new packaging was asked for.
**Consequences:** README badges use only facts in the repo; there is no `requires-python` to cite, so no Python-version badge unless it is verifiable another way.
**Date:** 2026-11-18

### Q5 - Demo and examples

**Rationale:** the demo is a client of the API, so it sits outside the package.

**Date:** 2026-11-18

### Q6 - Old diagram and PDF

**Rationale:** the PNG is a drawn diagram, not a tool screenshot.
**Consequences:** the diagram script and font files go under `docs/diagrams/`.
**Date:** 2026-11-18

### Q7 - "VPBank" naming
**Answer:** accepted the recommendation: README title "Financial agent", new diagram without the VPBank label, `app.py` title untouched.
